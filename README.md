# claude-mods

Personal Claude Code mods, published as a plugin marketplace.

## Install

```
/plugin marketplace add IfthisthenMaw/claude-mods
/plugin install agent-progress@claude-mods
```

The repository is private, so the machine installing from it needs read access to it.

## Mods

| Mod | What it does |
| --- | --- |
| [agent-progress](plugins/agent-progress) | Progress band above the prompt and an agents pane (`/agents-info`) for planned multi-agent work. |

Mods use Claude Code's hooks interface, which is early access and may change between releases.
